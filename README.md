# CyberSecNotes

A cyber-security note-taking app built with React + Vite.

## Features
- Dark cyberpunk UI
- Notes by threat category
- Rich metadata: severity, tag, date, IOC references
- Local encrypted vault using Web Crypto API
- Search and filter by category
- Export to JSON

## Getting started

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
